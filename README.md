# Associate-Data-Analyst-In-SQL
Here you will find all the path you need cover to become an Associate Data Analyst In SQL. In this repository there are different courses in order, from basic to advanced, and in addition you will find practical excercises to understand the theory.

For this project we will be using PostgreSQL (or Postgres), a powerful, open-source object-relational database management system (ORDBMS) known for its reliability, extensibility, and robust feature set, supporting both SQL and JSON querying for complex data workloads like web apps, analytics, and geospatial projects.
