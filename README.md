## 📖 About This Track

This repository documents my path through DataCamp's **Associate Data Analyst in SQL** career track: 12 courses plus 2 guided projects, taking SQL from a first `SELECT` statement all the way to window functions, exploratory data analysis, business-intelligence-style OLAP queries, and — beyond SQL itself — the statistics and data-communication skills an analyst needs to actually act on what a query returns.

All hands-on work uses **PostgreSQL**, a powerful, open-source object-relational database system known for its reliability, extensibility, and support for both SQL and JSON querying.

Each course folder contains its own **showcase notebook** — a portfolio-style writeup (not a copy of the raw slides) built from the official course material and, in the SQL-heavy courses, real query examples and results from a course dataset. The two project folders each contain a guided-project notebook working through a real analysis end-to-end.

## 📚 Course & Project Details

### 📌 Course 2 — Intermediate SQL
> Folder: [`2_Intermidiate-SQL`](./2_Intermidiate-SQL)

Querying, filtering, aggregate functions, and sorting/grouping data with PostgreSQL, practiced on a films/reviews/people dataset — from `COUNT()` and `DISTINCT` through `WHERE`/`LIKE`/`IN`/`NULL` filtering, `AVG()`/`SUM()`/`ROUND()`, and `GROUP BY`/`HAVING`.

---

### 🧩 Project 1 — Analyzing Students' Mental Health
> Folder: [`3_Project-1:Students_Mental_health`](./3_Project-1:Students_Mental_health)

Guided project using real, ethics-board-approved survey data from a Japanese international university to explore whether studying abroad affects mental health, and whether **social connectedness** and **acculturative stress** are predictive of depression risk among international vs. domestic students.

---

### 📌 Course 4 — Joining Data in SQL
> Folder: [`4_Joining_Data_In_SQL`](./4_Joining_Data_In_SQL)

All major SQL join types and set operations — `INNER`, `OUTER`, `CROSS` and `SELF` joins, set theory operations, and subqueries — practiced on a countries database (cities, economies, populations, languages, currencies).

---

### 📌 Course 5 — Data Manipulation in SQL
> Folder: [`5_Data Manipulation In SQL`](./5_Data%20Manipulation%20In%20SQL)

Advanced SQL data manipulation — `CASE` statements, subqueries, correlated queries, CTEs, and window functions — practiced on the European Soccer Database (12,800+ matches across 11 countries, 2011–2015).

---

### 📌 Course 6 — PostgreSQL Summary Stats and Window Functions
> Folder: [`6_PostgreSQL Summary Stats and Window Functions`](./6_PostgreSQL%20Summary%20Stats%20and%20Window%20Functions)

A deep dive into window functions using the Summer Olympics dataset (1896–2012): row numbering, fetching, ranking, paging, aggregate frames, pivoting with `CROSSTAB`, `ROLLUP`/`CUBE` subtotals, and string aggregation.

---

### 📌 Course 7 — Functions for Manipulating Data in PostgreSQL
> Folder: [`7_Functions for manipulating data in postgresql`](./7_Functions%20for%20manipulating%20data%20in%20postgresql)

PostgreSQL's built-in functions for common data types, using the Sakila DVD Rental database: data type exploration, date/time arithmetic, string parsing and manipulation, full-text search, user-defined types, and PostgreSQL extensions.

---

### 📌 Course 8 — Introduction to Statistics
> Folder: [`8_Introduction to statistics`](./8_Introduction%20to%20statistics)

A conceptual, Python-and-math-based course covering the statistical backbone behind data-driven decisions: descriptive statistics, probability, distributions, the Central Limit Theorem, correlation, and hypothesis testing.

---

### 📌 Course 9 — Exploratory Data Analysis in SQL
> Folder: [`9_Exploratory Data Analysis in SQL`](./9_Exploratory%20Data%20Analysis%20in%20SQL)

Exploring and understanding unfamiliar datasets purely with SQL, using real-world data (Stack Overflow questions, Fortune 500 companies, city service requests): database exploration, numeric summarization, categorical data cleaning, and date/time analysis.

---

### 📌 Course 10 — Data-Driven Decision Making in SQL
> Folder: [`10_Data-Driven Decision Making in SQL`](./10_Data-Driven%20Decision%20Making%20in%20SQL)

Applying SQL to business-intelligence scenarios with a `MovieNow` online rental database (`renting`, `movies`, `customers`, `actors`, `actsin`): KPI reporting, customer behavior analysis, advanced subqueries with `EXISTS`/`IN`, and OLAP operators (`CUBE`, `ROLLUP`, `GROUPING SETS`) for multi-dimensional analysis.

---

### 📌 Course 11 — Understanding Data Visualization
> Folder: [`11_Understanding Data Visualization`](./11_Understanding%20Data%20Visualization)

The principles behind choosing the right chart for the right data: distinguishing variable types, selecting appropriate plot types, using color and shape effectively, and avoiding common visualization pitfalls.

---

### 📌 Course 12 — Data Communication Concepts
> Folder: [`12_Data Communication Concepts`](./12_Data%20Communication%20Concepts)

Communicating data findings effectively to different audiences: data storytelling, identifying your audience, choosing written vs. oral formats, structuring reports, and building compelling presentations.

---

### 🧩 Project 2 — Analyzing Motorcycle Parts Sales
> Folder: [`13_Project-2_Motorcycle_Parts`](./13_Project-2_Motorcycle_Parts)

Guided project for a motorcycle parts company operating three warehouses (North, Central, West). Calculates **net wholesale revenue by product line**, month, and warehouse — accounting for different fees across credit card, cash, and bank-transfer payments — to support a board-level revenue review.

## 📁 Repository Contents

Course folders generally contain:
- **A showcase notebook (`.ipynb`)** — the polished, portfolio-ready writeup for that course, with explanations and runnable SQL examples.
- **`chapterN.pdf`** — official slide decks from the course.
- **`Resources/`** — datasets (CSV/zip) used for the course's SQL exercises, where provided.

The two guided-project folders (`3_...` and `13_...`) instead contain a single project `notebook.ipynb` plus the raw dataset(s) used in the analysis.
